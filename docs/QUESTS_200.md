# Pocket District — 200件のイベント発生型クエスト

この機能は既存の7種類の住民会話アクティビティ、配達、地域ジョブに**追加**されます。200件はすべて別ID（Q001〜Q200）、別タイトル、別の日本語ストーリーの発端、実際のイベントによる2段階の進行、個別の報酬を持ちます。200行を表示するだけの未接続のダミーではありません。

## 進行とUI

- 実際の条件成立時にクエストが自動発見されます。プレイヤーの意思と無関係に何十件も一気に開かないよう、**同時進行は最大3件**、同系統の新規発生には18秒の間隔があります。
- **CITY → 依頼** に進行中のタイトル、発端、2段階の進捗、GPSへ設定するボタン、依頼の中断、完了済みの記録と「完了数/200」を表示します。街で起きた事件はHUDにも通知します。
- GPSの目的地は店舗などの**実在する入り口**と、移動中のNPCの座標に追従します。行動のみで進む段階は誤った位置へワープさせず、必要な操作の説明を提示します。新規依頼はGPSが空いているときだけ自動選択し、既存の配達/街案内を勝手に上書きしません。
- 報酬は2段階を**本当に完了したときに一度だけ**支払われます。発見、画面を開く、建物へ近寄るだけで報酬は入りません。中断しても報酬は得られず、同じクエストは完了履歴により二重払いできません。
- 保存情報 `quest_journal` はオプションの辞書形式で、旧セーブにも対応します。途中段階、走行の残距離、完了済みIDを引き継ぎます。
- 住民との会話200話題×10導入パターンの独自文章は**変更しません**。既存の7種の会話アクティビティも残します。
- 戦闘遭遇は実際に警官と敵対者が戦っている短時間の街角イベントを追加します。巡回警官は非敵対で、プレイヤーに不当な手配をつけません。
- 車両事故は近接判定ではなく `move_and_slide` の物理衝突結果を利用し、速度条件と事故クールダウンで重複判定を防ぎます。

## 既知の範囲

この実装は「異なる出来事から始まり、既存システムを利用して完了する短編クエスト200件」の**第1段階**です。固有の長尺カットシーン、200人の専用NPC、独立した200個の室内、複雑なマルチエンディングは追加していません。進行中の戦闘は短い街角遭遇イベントとして表現し、会話本文に自動生成の定型繋ぎ文言を挿入しません。NPCへの音声・すべての室内での固有アニメーションは今後の拡張です。

- 既存のGodot 4.4.1/4.7.2自動テスト、100ケースの回帰試験、Android ARM64 APKビルド。
- JSONファイル5章は `export_presets.cfg` のinclude_filterでAPKとWebへ確実に収録します。
- 実機での長時間プレイや全200件を連続でプレイしての体験レビューは別途必要です。
