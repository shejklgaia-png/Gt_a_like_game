# 会話から派生する街の活動（2026-11-18）

## 目的と入口

住民との会話を単なる知識・雑談の閲覧で終わらせず、NPCに話しかける → 活動を選択 → CITYのGPSで現地へ移動 → 現地でACTION/会話 → 報酬と関係性を得る、といった街全体のゲームループへつなぐ。

- 路上で住民の近くに立ち、**ACTION** を押すと会話が開きます。従来の200話題×10導入パターンの専門知識・深掘り・自由な次話題移動はそのままです。NPCが話していない汎用台詞を合成・挿入しません。
- 会話の下側（必要に応じて縦スクロール）に、独立した **「この住民との会話から始める街の活動」** として、NPCの生活役割（買物・勤務・帰宅・外食）と現在の話題IDで変わる2件の参加可能な依頼を表示します。
- どちらかを選択すると会話が閉じ、住民が依頼主として記録され、CITY GPSが活動の第1目的地を案内します。
- 多くの依頼は2施設を訪問し、建物の入口の近くで **ACTION** を押して進行します。2地点目への道案内は自動で更新します。実際の店で商品の遠隔購入ができるわけではなく、これは簡易的な地域活動です。
- 「別の住民を紹介してもらう」は、**実際に別のNPCと会話を開始すること**で達成します。目的の住民が動けばGPSも追従し、対応する住民がいないときは新規の受注を提示しません。
- 完了で活動固有の現金報酬と、**依頼主との親密度+8**を獲得します。既存の配達や地域ジョブと進捗・報酬を分離しています。
- 同じ住民・同じ種類の活動の報酬は1度だけです。未受注の別の種類は、会話に戻ればその住民から受けられます。失敗や期限切れで縛らない代わりに、**CITY→仕事→住民の活動を辞退する**から報酬なしで解除できます。
- 会話には活動受注とは別に **「おすすめ：○○へ案内」** があり、店舗、ガレージ、物件、地域ジョブ掲示板など**既存の遊び**へGPSで直接つながります。紹介を受けただけでは報酬や購入は発生しません。

## 7種類の活動

| 活動 | 進行先または条件 | 報酬 |
| --- | --- | ---: |
| 食べ歩きの下見 | 飲食店 → スーパー | $120 |
| 職場まわりのお手伝い | オフィス → 市場 | $175 |
| 買い出しルート探し | 市場 → コンビニ | $135 |
| 部屋づくりの相談 | 家具店 → 住宅 | $145 |
| 夜の街の見回り | ラウンジ → クラブ | $180 |
| 車と街の施設を調べる | ガレージ → コンビニ | $150 |
| 別の住民を紹介してもらう | 指定された別の住民に話しかける | $160 |

住宅・店・ガレージ・地域ジョブへの「おすすめ」は、NPCの生活役割と話題ごとに異なり、実際の施設入口/受付へ誘導します。既存の各店・ジョブの操作を新規実装したという意味ではありません。

## 永続化・統合

- `scripts/conversation_activities.gd` が7種類、NPCごとに2つの提案、目的地・進捗、紹介先の動的追従、現地完了、報酬の二重取り防止、辞退、保存状態を管理します。
- `scripts/main.gd` が会話画面の活動/おすすめボタン、縦スクロール、ACTION・NPC交流の達成判定、現金・親密度・統計、GPSを統合します。
- `scripts/city_phone.gd` の「仕事」に進行中の住民依頼・辞退ボタンを追加し、「情報」に完了件数を表示します。
- `scripts/minimap.gd` では既存配達/地域ジョブとは別に、活動の目的地を琥珀色で示します。
- セーブデータの追加項目 `conversation_activities` は任意項目なので、旧セーブには初期値を適用します。記録するのは受注中の種類/依頼主ID/段階、完了済み住民・活動ペア、完了件数です。
- `scripts/conversation_activity_test.gd` がNPC全46人の候補、既存の会話本文が変わらないこと、ボタン→受注→GPS→施設ACTION→現金/親密度、2段階のセーブ復元、二重取得防止、実際の別NPCとの会話、既存システムへのおすすめ案内、辞退/保存を検証します。
- Godot 4.4.1/4.7.2 のCIとAndroid APK自動ビルドで確認します。実機のタップ操作・画面収まりは別途検証が必要です。

## 次回の計画

会話の内容をアクティビティにさらに深く反映するため、住民と現地で待ち合わせて同行するNPC行動、時間帯と関係性による提案の変化、会話のトピックに応じた専門的な小イベント、店内利用や家具購入と連動する条件付きミッションなどを段階的に実装します。既存の著作テキストに定型のつなぎ文は混入させません。
